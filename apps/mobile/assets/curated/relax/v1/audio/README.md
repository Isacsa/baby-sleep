# Relax Audio Assets

This folder should contain the following audio files (MP3, AAC, or M4A format):

## Required Files

1. **white_noise.mp3** - White noise (seamless loop, 30-60s duration)
2. **rain.mp3** - Rain sounds (seamless loop, 30-60s duration)
3. **fan.mp3** - Fan/ventilator sound (seamless loop, 30-60s duration)
4. **shush.mp3** - Shushing sound (seamless loop, 30s duration)

## Specifications

- Format: MP3 or M4A (AAC)
- Bitrate: 64-96 kbps mono
- Duration: 30-120 seconds (will be looped)
- Important: Edit files for **seamless looping** (no gaps/pops at loop point)
